# agenticeng.ru

Исходный код блога [agenticeng.ru](https://agenticeng.ru) — инженерные заметки об LLM-инфраструктуре, агентах и AI.

## Стек

- [Zola](https://www.getzola.org/) — статический генератор сайтов
- Яндекс Object Storage — хостинг статики
- Яндекс CDN — раздача контента

## Локальная разработка

```bash
zola serve
```

Сайт доступен на [http://127.0.0.1:1111](http://127.0.0.1:1111).

## Деплой

Деплой происходит автоматически при пуше в `main`.
